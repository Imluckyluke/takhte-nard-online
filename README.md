# تخته نرد آنلاین 🎲 | Online Backgammon (Takhteh Nard)

بازی کامل و استاتیک تخته نرد با فارسی‌سازی کامل، بدون نیاز به بیلد.
A complete static (no-build) online-multiplayer Backgammon web game, Persian-first.

## ✨ امکانات | Features

- 🎲 موتور کامل قوانین: چیدمان استاندارد، تاس‌کشی آغازین، جفت (۴ حرکت)، بار و ورود، زدن بلات، خروج (Bear off)، قانون «استفاده حداکثری از هر دو تاس»، مارس و سه‌خال (Gammon/Backgammon)
- 🎰 کیوب دوبل (تا ۶۴) با پیشنهاد/قبول/رد (رد = باخت)، همگام در حالت آنلاین
- 🌐 بازی آنلاین همتا‌به‌همتا با PeerJS: ساخت اتاق با کد ۵ حرفی + لینک دعوت (`?join=CODE`)، چت زنده، نمایش وضعیت اتصال
- 👥 حالت دو نفره روی یک صفحه | 🤖 حالت بازی با کامپیوتر (هوش حریصانه)
- 🔊 افکت صوتی با WebAudio (بدون فایل)، 📜 سوابق حرکت فارسی، 📱 ریسپانسیو و لمسی

## 🌐 بازی آنلاین | How to play online

1. یک نفر **«ساخت اتاق آنلاین»** را می‌زند (سفید می‌شود).
2. کد ۵ حرفی اتاق و **لینک دعوت** را برای دوستش می‌فرستد (مثلاً `https://USER.github.io/nard/?join=AB12C`).
3. نفر دوم لینک را باز می‌کند (یا کد را در کادر «ورود به اتاق» می‌زند) و مشکی می‌شود.
4. فقط نوبتِ طرفی که نوبتش است فعال است؛ هر تاس/حرکت/کیوب/چت خودکار همگام می‌شود.

## 📜 خلاصه قوانین | Rules summary

- سفید از ۲۴ به ۱ (کاهشی)، مشکی از ۱ به ۲۴ (افزایشی). خانه خودی سفید ۱–۶، مشکی ۱۹–۲۴.
- خانه با ۲+ مهره حریف مسدود است؛ مهره تنها (بلات) زده می‌شود و به بار می‌رود.
- مهره بار اول باید وارد شود (سفید: ‎۲۴−d‎، مشکی: ‎d‎)؛ ورود به خانه مسدود غیرمجاز است.
- خروج فقط وقتی همه ۱۵ مهره در خانه خودی‌اند: تاس دقیق، یا تاس بزرگ‌تر اگر مهره‌ای در خانه بالاتر نباشد.
- اگر هر دو تاس جداگانه ممکن‌اند ولی هیچ ترتیبی هر دو را مصرف نمی‌کند، فقط تاس بزرگ‌تر بازی می‌شود.
- کیوب فقط قبل از تاس و با مالکیت کیوب پیشنهاد می‌شود؛ رد کردن = باخت.

## 💻 اجرای محلی | Local run

بدون بیلد — فقط فایل را باز کنید (برای حالت آنلاین به اینترنت/HTTPS نیاز است):

```bash
cd /tmp/nard
python3 -m http.server 8000
# باز کنید: http://localhost:8000/
```

## 🚀 انتشار | Deploy notes

دیپلوی خودکار با GitHub Pages از طریق `gh-pages`/`Actions` انجام می‌شود
(`.github/workflows/pages.yml`): با هر پوش به `main` فایل‌های استاتیک منتشر می‌شوند.
نیازی به بیلد نیست؛ کافی است Pages روی **GitHub Actions** تنظیم شده باشد.
PeerJS از ابر عمومی PeerJS استفاده می‌کند (پیشوند `takhtenard-v1-`) — بدون سرور اختصاصی.
